# References and Technical Documentation

The following resources provide documentation for tools and evaluation methods that may be used when implementing the proposed model evaluation strategy.

## 1. Scikit-learn

Scikit-learn provides machine learning algorithms and evaluation functions for regression models.

Documentation: https://scikit-learn.org/stable/

Relevant topics:
- Regression metrics
- Model evaluation
- Train-test splitting
- Model selection and validation

## 2. Pandas

Pandas provides tools for data cleaning, manipulation, and analysis.

Documentation: https://pandas.pydata.org/docs/

## 3. NumPy

NumPy provides numerical computing functions useful for data processing and mathematical operations.

Documentation: https://numpy.org/doc/

## 4. Matplotlib

Matplotlib can be used to create plots for comparing evaluation results and examining prediction errors.

Documentation: https://matplotlib.org/stable/

## 5. Seaborn

Seaborn provides statistical visualization tools that can support exploratory analysis and evaluation reporting.

Documentation: https://seaborn.pydata.org/

## 6. Evaluation Metrics

The planned regression metrics are Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and the coefficient of determination (R-squared). Their definitions and interpretation should be checked against the official Scikit-learn documentation before the final experimental report is completed.

## Notes

These are technical references for the proposed workflow. They do not represent evidence that model experiments have already been completed.

The final report should document the actual dataset source, experimental setup, evaluation results, and any additional sources consulted during practical implementation.
